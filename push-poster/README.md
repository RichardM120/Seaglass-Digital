# PUSH open casting poster

Source for the revised PUSH casting poster (Catherine Willis Casting).

- `Main.dc.html` — the poster artboard, A4 portrait at 96 ppi (794 × 1123 px).
- `canvas.json` — artboard layout and launch view.

Both are edited by hand. The published canvas is seeded from them; the
generated `push-casting-poster.html` is build output and is not tracked.

## Copy
